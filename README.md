# Буревестник — процедурный галеон

Трёхмачтовый пиратский галеон в открытом море, целиком сгенерированный кодом в браузере. Ни одной модели, картинки или звукового файла: корпус, паруса, такелаж, текстуры, небо, океан, острова и звук синтезируются при загрузке.

**Запуск:** скачай `index.html` и открой двойным кликом. Интернет не нужен, всё (включая three.js) внутри одного файла.

## Что внутри

- **Корабль** — обводы галеона по таблице шпангоутов, медная обшивка днища, крашеные пояса с позолоченным фризом, 50 орудийных портов с пушками, корма с двумя рядами окон, гербом и балконами, золотой морской дракон на носу, фонари, шлюпка, бочки, штурвал, якоря.
- **Паруса** — 14 парусов, надуваются по видимому ветру, хлопают при потере ветра, убираются к реям. Реи сами брасопятся под ветер. Флаги — симуляция ткани (Верле).
- **Такелаж** — ванты с выбленками, штаги, бакштаги, бегучие концы, которые двигаются вместе с реями.
- **Океан** — 12 волн Герстнера, одинаковых в шейдере и в JS, поэтому корабль качается ровно на тех волнах, что видно. Пена на гребнях, подсветка гребней на просвет, пенный след и волны Кельвина за кормой, отражение корабля в воде.
- **Небо** — рассеяние в атмосфере, солнце и луна по времени суток, облака, звёзды, Млечный путь.
- **Погода** — от штиля до шторма: волны, тучи, дождь, молнии, автоматическое рифление парусов.
- **Бой** — бортовой залп волной от носа к корме: вспышки, искры, пороховой дым, откат стволов, ядра по баллистике, всплески.
- **Мир** — процедурные острова с пляжами, пальмами и прибоем, маяк с лучом, чайки.
- **Звук** — Web Audio: волны, плеск у носа, скрип при качке, ветер, дождь, выстрелы с задержкой по расстоянию, гром, чайки.

## Управление

| Клавиша | Действие |
|---|---|
| A / D | руль |
| W / S | поставить / убрать паруса |
| Q / E | залп левым / правым бортом |
| C | камера: орбита, кино, палуба |
| 1–4 | рассвет, день, закат, ночь |
| T | шторм |
| P | автопилот |
| H | скрыть интерфейс |
| мышь / колесо | обзор / зум |

## Сборка из исходников

Нужен Node.js 18+.

```
node build.mjs
```

Скрипт склеивает `vendor/three.module.min.js` и `src/*.js` по шаблону `template.html` в один `index.html` и проверяет синтаксис.
